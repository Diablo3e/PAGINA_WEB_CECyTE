# Scripts externos
- [Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/): Plantillas de elementos comunes en páginas web como (botones, cartas, acordeones, listas, barras de navegación, etc.), funciona por medio de clases y otros atributos pre-establecidos que deben incluirse en elementos HTML, por ejemplo `<button type="button" class="btn btn-primary mb-5">`, su implantación en el proyecto es por medio de archivos bootstrap.min.

# Laravel
- [Laravel](https://laravel.com/docs/12.x): Framework de PHP usado para facilitar desarrollo web, la estructura de las carpetas es debido a su uso
    - [Blade](https://laravel.com/docs/12.x/blade#main-content): Vistas creadas con Laravel tienen la terminación ".blade.php", indicando que es posible usar caracteres especiales para editar código HTML.

# Dependencias de Laravel utilizadas
- [Ziggy](https://github.com/tighten/ziggy): Dependencia incluida en el proyecto para permitir el uso de las rutas Laravel existentes en `\routes\web.php` en código JavaScript, para que funcione se tiene que incluir `@routes` en la vista relacionada con el código JS y usar `route(nombre.ruta, dataEjemplo)` en el código JS. (En el proyecto `@routes` está incluido en la plantilla principal y, por lo tanto, funciona globalmente)
- [jQuery](https://api.jquery.com/): Biblioteca de JavaScript que simplifica la manipulación del DOM, manejo de eventos, animaciones y peticiones AJAX. Funciona mediante funciones predefinidas que se aplican a elementos HTML usando selectores similares a los de CSS. Por ejemplo: `$('#miElemento').hide();` oculta un elemento con `id="miElemento"`, o `$('.miClase').click(function() { ... });` asigna una función al evento click de todos los elementos con la clase miClase.
- [FIlament v4](https://filamentphp.com/docs/4.x/introduction/overview): Dependencia de Laravel que facilita la creación de paneles de usuario, en este caso está configurado para que el login se vea cuando se va a la liga `https://nombreDominio.com/admin`, filament funciona con la información que existe en la base de datos, y todas las entradas hechas en el panel e incluso los usuarios existen ahí.
